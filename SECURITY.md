Use GitHub's **Report a vulnerability** option in this repository's Security tab (private vulnerability reporting). Please do not open public issues for suspected security problems.

## Security scope (JumpCut)

This application asks for **Accessibility** permission because it needs an active session event tap to suppress real Dock swipes. Accessibility is a broad macOS grant; the app's code deliberately uses a narrower subset.

## What this revision does

- Only taps raw CoreGraphics gesture event kinds 29 and 30; no global keypress event tap. Optional keyboard shortcuts are registered with Carbon and **off by default**.
- Constructs synthetic Dock-swipe events and a macOS 27 serialized IOHID companion event. Both are explicitly tagged after serialization; input generated by JumpCut is passed through rather than re-intercepted.
- Reads current Space/display topology via undocumented CGS APIs. It does not write system Spaces settings.
- Stores only local application preferences through `UserDefaults`.
- Installs a menu-bar app. There is no background daemon, automatic update service, network telemetry, or process injection. App installation copies `JumpCut.app` to /Applications and opens the Accessibility settings pane.

## Risks

- The reviewed code's limited use of Accessibility is **not** a technical sandbox limit; granting Accessibility to any app gives it significant power.
- Private CGS and IOHID structures can change on any OS update, possibly causing no switching, reversed direction, or blank desktop surfaces.
- A synthetic event can be posted but ignored by the Dock. Unit tests cannot conclusively test macOS's on-screen compositor.
- Local source builds are ad-hoc signed, so each rebuild is a new code identity to macOS and may need Accessibility re-granted. The pinned Apple Development signing path (`Scripts/macos-sign.py`) is available only to the maintainer: it depends on repository secrets and a certificate pinned to this project, its builds are **not notarized**, and its CI artifacts are smoke tests, not releases.
- No independent security audit or end-to-end macOS 27 hardware validation has been completed.

Root app code should not add networking, subprocess execution, clipboard reads, key logging, or modify system preferences for this feature. Source provenance and historical upstream security notes: [docs/UPSTREAM_STRAFE_SECURITY.md](docs/UPSTREAM_STRAFE_SECURITY.md).
